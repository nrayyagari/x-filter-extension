## Name
X Filter — Political & Gossip Blocker

## Short Description (132 chars)
Filter political, gossip, sensationalist & international relations content from X.com while preserving tech posts.

## Detailed Description

**Take control of your X.com (Twitter) timeline.**

X Filter blocks unwanted political discourse, movie gossip, international conflict noise, and sensationalist clickbait — while keeping the tech, programming, and startup content you actually want to see.

### How it works

X Filter uses a weighted scoring engine to evaluate every tweet on your timeline:

- **Political content** (+2 per keyword) — Indian politics (Modi, BJP, Congress, elections, etc.)
- **Movies & Gossip** (+2 per keyword) — Tollywood, Bollywood, box office, celebrity drama
- **Sensationalism** (+1 per keyword) — "Breaking", "Shocking", "Exposed", clickbait headlines
- **International Relations** (+2 per keyword) — Trump, Russia-Ukraine, Iran, geopolitics, military conflicts
- **Tech Protection Override** — If ANY tech term is found (Kubernetes, AI, programming, etc.), the tweet is NEVER hidden, even if it scores above the threshold
- **Learned patterns** — Authors (+3), hashtags (+2), and keywords (+1) you mark via "Hide similar"

A tweet scoring ≥3 is replaced with a clean placeholder showing the reason.

### Features

- **4 independent filter categories** — toggle each one on/off separately
- **Hover to reveal** — hover over any hidden post to temporarily see it
- **Hide similar** — click to teach the filter from mistakes; it learns the author, hashtags, and keywords
- **Always show @author** — permanently whitelist an author so their posts are never filtered
- **Keyboard shortcut** — press Shift+H on a focused tweet to trigger "Hide similar"
- **Advanced settings** — edit keyword lists, manage blocked/whitelisted authors, view statistics
- **Export/Import** — save and restore all settings as JSON
- **100% local** — no external APIs, no cloud sync, no analytics, no data collection

### Privacy

All data stays on your device in chrome.storage.local. X Filter does not collect, transmit, or share any personal data. See our privacy policy for details.
